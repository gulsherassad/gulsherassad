# Gulsher Assad

CS student at UBC Okanagan, based in Kelowna, BC.
I mostly build Python backends with a model doing something non-trivial behind
them — statistical forecasting, constrained optimization, and the API and
frontend work to make them usable.

## Projects

**[epl-predictor](https://github.com/gulsherassad/epl-predictor)** — Premier
League match forecaster combining an Elo rating system with a Poisson goals
model. 54.9% accuracy across a 1,420-match walk-forward backtest, roughly at
betting-market level. FastAPI + scikit-learn, deployed on Render.
[Live demo →](https://epl-predictor-xmqs.onrender.com)

**[macro_optimizer](https://github.com/gulsherassad/macro_optimizer)** — Meal
planning as a constrained linear program: minimize calories subject to a protein
floor, calorie ceiling, and optional carb/fat ranges. Solved with PuLP, served
through FastAPI with a React frontend. Infeasible targets return structured
explanations rather than an error.

**[ByteMe-Project](https://github.com/gulsherassad/movie-review-platform)** — Movie
review platform built by a team of four for UBCO COSC 310. FastAPI backend,
Next.js frontend, containerized with Docker Compose. I owned the review and
comment modules.
